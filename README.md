# SpringCard PC/SC-like Keyple plugin for Android (archived)

> **This repository is archived and remains available as a reference resource.**

This plugin enables Android applications using Eclipse Keyple to communicate with compatible SpringCard smart card readers over USB or Bluetooth Low Energy (BLE), through the SpringCard PC/SC-like library.

The project is no longer actively maintained. Its source code remains available to help developers explore Keyple integration with SpringCard readers on Android.

## Example application

The [example-app](example-app/) folder contains a sample application supporting USB and BLE connections and demonstrating a Calypso transaction with or without a Secure Access Module (SAM).

## Documentation

The [API reference](https://springcard.github.io/android-keyple/) provides details on the plugin's interfaces. The underlying [SpringCard PC/SC-like library for Android](https://github.com/springcard/android-pcsclike) is also available as an archived reference.

When reusing this plugin or its example, review and adapt them to your target Android and Keyple versions, development tools and reader model.
